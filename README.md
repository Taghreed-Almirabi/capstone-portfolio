# Taghreed Almirabi — Capstone Portfolio

Portfolio site for my MSIT capstone project at the University of the People (MSIT 5910-01, AY2027-T1):
**Designing and Evaluating an Integrated Access Control Framework for Electronic Health Records in a Saudi Government Hospital.**

Live site: https://taghreed-almirabi.github.io/capstone-portfolio/

Source code of the project itself: https://github.com/Taghreed-Almirabi/Integrated-EHR-Access-Control-Framework

## What is on the site

- A live, in-browser demo of the access-decision engine (same rules as `src/access_control_engine.py`, release v1.2.0-unit7).
- Problem, approach and results in one page.
- Evidence: measured results, test-suite breakdown, evaluation chart and links to the files that produced them.
- Deliverables: final report, presentation, demo video, source code, design documents and release history.

## Files

files/Taghreed_Almirabi_Capstone_Report.pdf        Final capstone report

## Publishing with GitHub Pages

1. Create a public repository named `capstone-portfolio`.
2. Upload `index.html`, this `README.md`, and the `files/` folder with the two PDFs.
3. In the repository, open **Settings → Pages**, set **Source** to *Deploy from a branch*, choose **main** and **/ (root)**, then save.
4. After a minute the site is live at `https://taghreed-almirabi.github.io/capstone-portfolio/`.

## Before sharing the link

In `index.html`, replace the two placeholders:

- `https://www.youtube.com/watch?v=REPLACE_WITH_VIDEO_ID` → the demo video link.
- `https://www.linkedin.com/in/REPLACE_WITH_YOUR_PROFILE` → your LinkedIn profile URL.

All data shown on the site and in the project is synthetic. No real patient information is used anywhere.
